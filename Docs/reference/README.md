## Why this one is kept

Its **Annexure VI** contains the questionnaire replies from individual almanac
makers, giving each panjika's adopted solar-year length, ayanamsa, precession
rate, and calculation method. That is the only published statement of the
Odrik-school parameters found anywhere — see
[../SURYASIDDHANTA_PANJIKA.md](../SURYASIDDHANTA_PANJIKA.md) §6.

Note the text is OCR'd and imperfect ("Paficanga" for "Pancanga", scrambled
column alignment in places). Annexure V is the list of panchangas received;
Annexure VI the replies. Search for `ANNEXURE  V` (two spaces) to locate them.
